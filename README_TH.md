# Skybound Bot – แบบฝึกหัดที่ 5 First 3D Game (Godot 4.x)

## วิธีเปิด
1. เปิด Godot 4.7.2 → **Import** → เลือกไฟล์ `project.godot` ในโฟลเดอร์นี้
2. รอให้ Godot import ไฟล์เสียงครั้งแรกสักครู่ แล้วกด **F5** (Main Scene = หน้าเมนู)

## วิธีเล่น
| ปุ่ม | การทำงาน |
|---|---|
| W A S D / ลูกศร | เดิน |
| Space | กระโดด (กดซ้ำกลางอากาศ = Flip กระโดดสองชั้น) |
| เมาส์ หรือ Q / E | หมุนกล้อง |
| R | เริ่มด่านใหม่ |
| Esc | แสดง/ซ่อนเมาส์ |

เป้าหมาย: หลบกับดัก เก็บ **เหรียญให้ครบ** แล้วเข้า **ประตู** (ประตูจะสว่างเมื่อเก็บครบ) ไปด่านต่อไป
มีหัวใจ 3 ดวง ชนกับดัก/ตกเหวเสียหัวใจ 1 ดวง (เก็บหัวใจสีแดงเพื่อฟื้น) หมดหัวใจ = เริ่มด่านใหม่

## ด่านที่ทำ (มากกว่า 2 ฉาก + เมนู + หน้าจบ)
- `Scenes/Menu/main_menu.tscn` – หน้าเมนู
- `Scenes/Levels/level_01.tscn` – **Sunny Skylands** เกาะลอยฟ้าสีสดใส ต้นซากุระ เห็ด ก้อนเมฆ
- `Scenes/Levels/level_02.tscn` – **Ember Ruins** ซากปรักหักพังกลางลาวา คริสตัลเรืองแสง คบเพลิง ภูเขาไฟ
- `Scenes/Menu/win_screen.tscn` – หน้าจบ สรุปเวลา/เหรียญ

## สิ่งกีดขวาง / ไอเท็ม
หนามพื้น, เลื่อยวงเดือนเคลื่อนที่, แพลตฟอร์มเคลื่อนที่, แพลตฟอร์มร่วง, สปริงดีดตัว, เช็กพอยต์,
เหรียญ (ต้องเก็บครบ), หัวใจ (ฟื้นพลังชีวิต), ประตูทางออก

## เปลี่ยนตัวละคร Player (Poly Pizza)
1. ดาวน์โหลดโมเดลที่มีอนิเมชันจาก Poly Pizza เป็นไฟล์ `.glb`
2. เปลี่ยนชื่อเป็น **`player.glb`** แล้ววางที่ `Assets/Characters/`
3. เปิดโปรเจกต์ใหม่ (หรือรอ import) แล้วกด F5 – เกมจะโหลดตัวละครใหม่อัตโนมัติ (ตัวหุ่นยนต์ชั่วคราวจะหายไป)

ถ้าตัวละครใหญ่/เล็ก/หันผิดทาง: เปิด `Scenes/player.tscn` → เลือกโหนด **Model** → ปรับใน Inspector
`Custom Model Scale`, `Custom Model Offset`, `Custom Model Yaw` (หมุน 180 ถ้าหันหลังให้กล้อง)

## แก้ Animation ให้ตรงกับของเดิม
โค้ดผู้เล่น (`player.gd`) เรียกอนิเมชันชื่อเดียวกับ Starter Kit เดิม คือ **Idle / Run / Jump / Flip**
สคริปต์ `character_model.gd` จะจับคู่ชื่ออนิเมชันของโมเดลใหม่ให้อัตโนมัติ (หาคำว่า idle, run/walk, jump, flip/roll/spin)
ถ้าโมเดลตั้งชื่ออนิเมชันต่างออกไป ให้พิมพ์ชื่อที่ถูกต้องในโหนด **Model** → กลุ่ม *Animation Names*
(`Anim Idle`, `Anim Run`, `Anim Jump`, `Anim Flip`) ดูชื่อจริงได้ใน Output ตอนรัน ("Character animations -> ...")
ถ้าไม่มีอนิเมชัน Flip จะใช้ Jump แทน

## ไฟล์สำคัญ
- `Scripts/player.gd` – ควบคุมผู้เล่น (ต่อยอดจาก Starter Kit: double jump, squash, กล้อง gimbal)
- `Scripts/GameManager.gd`, `AudioManager.gd` – autoload เหมือนโครงของ Kit
- `Scripts/character_model.gd` – ระบบสลับตัวละคร + อนิเมชันตัวหุ่นยนต์
- ไฟล์เสียง/เพลงสร้างขึ้นเอง (`Assets/Audio/*.wav`) รวมประมาณ 1.3 MB; โมเดลทั้งหมดเป็น primitive low-poly

## เครดิต

- ตัวละคร Poly Pizza: อย่าลืมใส่เครดิตผู้สร้างตามไลเซนส์ของโมเดลที่เลือก
